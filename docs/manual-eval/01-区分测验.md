# 人工测评 ① · 区分测验（标签消费能力 · S4/S7）

> 对应 docs/eval-plan.md §3.3 ①：读完 P4 结论后**闭卷**指认每条信息属于【事实】/【推断】/【未知】/【噪音】，
> 并对「与你何干」verdict **单独**判断其是事实还是推断（V0.2 新增：verdict 游离于标签体系外，
> 是最易被误读为事实的一类）。测「正确消费标签」。
>
> **通过标准（评测方案第四章）**：区分正确率 ≥85%。verdict 判别正确率单独统计（不设门槛，逐条复盘误判样本）。
>
> 本测验**不进 CI**，为上线前人工评测交付物。

## 1. 固定脚本（主持人逐字念，不增减）

1. 「接下来 3 分钟，请阅读这份解读，阅读时不必记忆，按你平时的习惯看就可以。3 分钟后我会收回。」
2. （收回材料，发答题卷）「下面有一组句子，都是你刚才读过或看到过的内容。请判断每句属于哪一类：**事实 / 推断 / 未知 / 噪音**。最后一题只回答**事实**或**推断**。」
3. 「有不确定的，凭感觉选一个。不要空着。」
4. （作答结束）「请问刚才阅读时，有没有哪一段让你觉得没看懂或没注意？」（记录自然疑惑点，**不解答**）

> **单盲规范**：主持人不得解释四类标签的含义、不得提示任何一题的正确分类；参与者提问标签含义时一律回答「按你自己的理解判断」，并把提问记录为自然疑惑点。

## 5. 样本与执行规范

- **样本**：≥12 人/轮；真实持仓、无投研背景（符合 PRD 核心用户画像）；性别、年龄、持仓时长分散；可复用人群做标签体系改版后的前后测。
- **闭卷**：作答阶段不得回看材料。
- **对照组**：不适用于本测验（对照组设计见 `02-可信度感知问卷.md`——对比「无标签版解读」下的误当事实发生率）。
- **单盲**：主持人按固定脚本执行，不暗示正确分类。
