# 人工测评 ② · 可信度感知问卷（误当事实发生率 · S4/S7）

> 对应 docs/eval-plan.md §3.3 ②：7 点李克特量表——「你多大程度上认为以下【推断】条目是**已经发生、确定无误的事实**？」
> 测「误把推断当事实」的**感知面**。标签格式正确 ≠ 用户真的不误读，本问卷补上认知层的证据。
>
> **通过标准（评测方案第四章）**：误当事实发生率 ≤15%（按条目平均，标签版组）。
> 对照组（无标签版解读）用于对比标签体系的增益，不设门槛。
>
> 本问卷**不进 CI**，为上线前人工评测交付物。

## 0. 设计

- **实验组（标签版）**：参与者阅读 `01-区分测验.md` 第 0 节的 P4 结论（带【事实】/【推断】/【未知】/【噪音】标签），随后作答。
- **对照组（无标签版）**：参与者阅读下方「无标签版解读」（同样的信息、去掉全部标签与假设/置信度标注，模拟「纯推送 + 原始资讯」形态），随后作答。
- **单盲**：两组的任务指令完全相同；主持人不得解释标签含义、不得提及「推断」「事实」等分类概念。对照组全程不接触标签体系。
- **指标定义**：某条【推断】条目被判为「已发生事实」= 该参与者对该条目打分 ≥5（7 点量表）。**误当事实发生率** = 按条目平均的 ≥5 分人数占比。

## 4. 统计与判定

- 对 Q1–Q4 每条：`该条目误当事实率 = 打分 ≥5 的人数 / 组内有效人数`
- **误当事实发生率（组）= Q1–Q4 四条平均**。
- **判定**：标签版组 ≤15% 通过；对照组结果用于对比（预期标签版组显著更低——「标签体系降低误读」的产品价值证据），并单独统计 Q4（verdict）的误当事实率，重点复盘。
- 若标签版组某单条 ≥30%，无论总均分如何，该条目标签/措辞进入回改清单。

## 6. 样本与执行规范

- **样本**：≥12 人/组/轮（两组共 ≥24 人）；真实持仓、无投研背景；性别、年龄、持仓时长分散；标签版与对照组随机分配，可复用人群做标签体系改版后的前后测。
- **单盲**：主持人只念固定脚本；不提示标签含义；对照组全程不接触标签概念。
- **材料隔离**：对照组不得看到 `01-区分测验.md` 的标签版材料；两组作答顺序随机。
- **对照组口径说明**：对照组模拟的是「不做噪音过滤与标签解释、只做推送+资讯拼接」的形态，用于回答「标签体系是否真的降低了误读」，不是本产品的另一形态。
