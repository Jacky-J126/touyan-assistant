## 原型交互点清单（V0.2）

以下为 Demo 中**真实可交互**的环节：

- **P1 澄清表单**：三字段必填校验，示例占比/成本/期限
- **P3 结论前确认**：可「跳过确认」并提示已记录
- **P4 「与你何干」段**：按表单输入**实时计算**——占比 15% 阈值判断、期限 vs 审批周期、成本相对现价 ±%；「噪音已过滤」折叠面板逐条附过滤理由与判定标准（相关性 · 信源 · 时效）；「术语白话（新手档）」折叠；未知信息区分「需你补充 / 需你等待」
- **P5 升级路径**：连续追问买卖建议两次 → 再引导 → 「本话题到此为止」停止作答

以下为**预置演示**（静态内容，非真实能力）：多源召回、噪音过滤引擎、事实/推断分离、拒答话术、术语熟悉度自适应。

> 注意：Demo 中个性化计算的演示默认参数（18.40 / 18% / 1–3 年）仅为演示兜底；真实系统不得内置默认持仓参数（违反「AI 不得替你假设」红线）。
