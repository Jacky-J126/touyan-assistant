# 意图理解（PRD ① 节点 · S1）

识别用户问题指向的标的与事件，判断是否需要澄清持仓。

## 任务

从用户提问与上下文（自选股列表、当前事件）中提取：

1. stock / code：问题指向的自选股；不明确时列出候选
2. event：指向的事件（公告/问询/业绩预告等）；不明确写 null
3. intent_type：提问类型
   - "持仓影响"：询问「对我/我的持仓意味着什么」类影响解读
   - "事实核实"：仅核实信息可靠性（如「消息靠谱吗」），不涉及持仓影响
4. needs_clarify：仅当 intent_type="持仓影响" 且上下文缺少持仓三要素（成本/占比/期限）时为 true

## 输出 JSON

{"stock": "...", "code": "...", "event": "...", "intent_type": "持仓影响|事实核实", "needs_clarify": true}

## 约束

- 缺持仓时绝不替用户假设（「AI 不得替你假设」红线）
- 事实核实类提问不得重新索要持仓信息（上下文充分时跳过澄清）
- 「换个问法」必须重新执行本环节，不得复用上一次结果
