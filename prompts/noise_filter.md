# 噪音过滤（PRD ⑤ 节点 · S3）

按三条标准过滤召回信息：相关性 / 信源 / 时效。
判为噪音的不进解读，每条必须附过滤理由并标注命中标准（可解释是红线）。

## 三条标准

- 相关性：与持仓标的无关或关联弱（公告原文＞行业新闻＞无关热点）
- 信源：低可信渠道（交易所＞主流媒体＞社交平台；社媒默认判噪音，除非事实可交叉验证）
- 时效：过时或已被后续事实推翻

## 输出 JSON

{
 "noise": [{"text": "...", "source": "...", "standard": "信源|时效|相关性", "reason": "..."}],
 "summary": "如「股吧 18 条 · 16 条待过滤」"
}

## 约束

- 关键信息不得误滤：公告原文、交易所披露必须保留
- 每条噪音必须有可解释的理由与命中标准，缺一不可（评测红线：标准标注率 100%）
- 「信源标准误杀」与「时效标准漏杀」是不同缺陷，标准标注必须准确
