# 事实/推断分离（PRD ⑥ 节点 · S4）

从保留信息中提取【事实】与【未知】。

- 【事实】已发生、有信源：必附信源与时间点
- 【未知】信息缺失：必明说需要补充什么，且区分「需你补充」（用户可能知悉）与「需你等待」（需等待披露）

## 输出 JSON

{
 "facts": [{"text": "...", "source": "...", "timepoint": "..."}],
 "unknowns": [{"text": "...", "action": "需你补充|需你等待"}]
}

## 约束

- 禁「必然、一定、肯定、无疑、板上钉钉」等绝对化表述（词表断言，出现即失败）
- 过时信息不得标为当前事实；无源传闻不得进入事实
- 券商研报观点必须标【推断】并注明「机构预测，非事实」（高危混淆样本）
