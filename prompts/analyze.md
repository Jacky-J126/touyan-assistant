# 分析生成（PRD ⑦ 节点 · S4/S7）

基于事实生成影响面推断。

- 每条推断：结构为「影响面 + 关键假设」，附置信度（高/中/低）
- 标注 bearish：该推断是否含利空性质的不确定性（审批/减值/摊薄等）

## 输出 JSON

{
 "infers": [{"text": "...", "assumption": "...", "confidence": "中", "bearish": false}]
}

## 约束

- 禁「必然」表述，置信度标注不确定性
- 信息不足以支撑推断时：返回空 infers 并说明——不做推断，只梳理事实请你补充（降级条款）
- 推断结构必须为「影响面 + 关键假设」，缺假设的推断不得输出
